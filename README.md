# Telegram-бот для заданий в групповом чате

Бот для супергруппы с темами (форумом):

- **По темам** — у каждой темы свои автоответы на ключевые слова, своё описание и свои задания.
- **Задания** — админ публикует задание в теме, бот закрепляет его и принимает сдачи от участников.
- **Запросы** — участники задают вопросы командой `/ask`, админ отвечает из лички, ответ приходит в тему.
- **Оценка** — каждая сдача приходит админу в личку с кнопками `1–5 ⭐` / `❌ Отклонить` / `💬 Комментарий`. Результат бот публикует в теме.
- **Напоминания** — за N часов до дедлайна бот упоминает тех, кто ещё не сдал; после дедлайна пишет итог.
- **Статистика админу** — `/stats` (рейтинг участников, % выполнения, средние оценки), `/export` в CSV и автоматический ежедневный отчёт.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. **Отключите privacy mode**: BotFather → `/mybots` → бот → *Bot Settings* → *Group Privacy* → *Turn off*.
   Без этого бот не видит обычные сообщения (сдачи, ключевые слова).
3. Добавьте бота в группу и сделайте **администратором** (права: удаление и закрепление сообщений, управление темами).
4. Каждый админ должен один раз написать боту `/start` в личку — иначе бот не сможет присылать ему работы и отчёты.
5. Настройте и запустите:

```bash
cp .env.example .env        # впишите BOT_TOKEN, ADMIN_IDS, GROUP_ID
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m bot
```

Или в Docker:

```bash
docker build -t tasks-bot .
docker run -d --env-file .env -v $(pwd)/data:/app/data --restart unless-stopped tasks-bot
```

ID группы можно узнать, переслав сообщение из группы боту [@getidsbot](https://t.me/getidsbot); свой ID — у [@userinfobot](https://t.me/userinfobot).

## Настройки (`.env`)

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от BotFather |
| `ADMIN_IDS` | Telegram ID админов через запятую — они управляют ботом и получают статистику |
| `GROUP_ID` | ID группы; если пусто — бот работает в любой группе |
| `DAILY_REPORT_TIME` | время ежедневного отчёта, `ЧЧ:ММ` |
| `TIMEZONE` | часовой пояс для дедлайнов и отчётов, например `Asia/Tashkent` |
| `REMIND_BEFORE_HOURS` | за сколько часов до дедлайна напомнить |
| `DB_PATH` | файл базы SQLite |

## Как пользоваться

### Админ в теме группы

```
/topic Математика                         — название темы (новые темы определяются автоматически)
/welcome Здесь задачи по алгебре...       — описание/правила темы (участники видят по /info)
/faq_add дедлайн | Сдать до пятницы 18:00 — автоответ: бот ответит, если в теме упомянут «дедлайн»
/faq_del дедлайн                          — удалить автоответ
/task Решить задачи | Стр. 15, №1–10 | 30.10.2026 18:00
                                          — опубликовать задание (описание и дедлайн необязательны)
/close 3                                  — закрыть задание №3, итог придёт в личку
/stat 3                                   — итог по заданию №3 в личку
```

### Участник

- **Сдать задание** — ответить (reply) на сообщение с заданием текстом, фото, файлом и т.д.
  Если в теме одно открытое задание, можно просто написать `#сдаю` (с текстом/фото).
  Отклонённую работу можно пересдать тем же способом.
- `/tasks` — задания темы и мой статус по каждому
- `/info` — описание темы, `/faq` — частые вопросы
- `/ask текст` — вопрос администратору
- `/my` — моя статистика

### Админ в личке бота

- Карточки сдач с кнопками оценки (если админов несколько, карточка обновится у всех — двойной проверки не будет)
- `/stats` — общая статистика и рейтинг
- `/pending` — что ждёт проверки, `/requests` — открытые вопросы
- `/export` — все сдачи в CSV (открывается в Excel)
- `/close id`, `/stat id`

## Структура

```
bot/
  __main__.py      запуск, регистрация команд
  config.py        настройки из .env
  db.py            SQLite: темы, автоответы, участники, задания, сдачи, запросы
  services.py      публикация заданий, приём сдач, уведомления
  stats.py         отчёты и CSV
  scheduler.py     напоминания о дедлайнах и ежедневный отчёт
  handlers/group.py  команды и сообщения в группе
  handlers/admin.py  личка админа: оценка, ответы, статистика
```

Участники попадают в статистику («не сдали»), когда хотя бы раз пишут в группе или вступают в неё
после добавления бота — Telegram не даёт ботам получить полный список участников.
