# Telegram-бот для заданий в групповом чате

Бесплатно работает на **Cloudflare Workers** (база — Cloudflare D1).

- **По темам** — у каждой темы свои автоответы на ключевые слова, своё описание и свои задания.
- **Задания** — админ публикует задание в теме, бот закрепляет его и принимает сдачи участников.
- **Оценка** — каждая сдача приходит админу в личку с кнопками `1–5 ⭐` / `❌ Отклонить` / `💬 Комментарий`, результат бот пишет в теме.
- **Запросы** — участник пишет `/ask вопрос`, админ отвечает кнопкой «Ответить», ответ приходит в тему.
- **Фото-исправления** — в выбранной теме под каждым фото кнопка «📷 Отправить фото исправление». Нажавший присылает исправленное фото; бот убирает оба исходных фото и публикует их одним альбомом: кто прислал нарушение, кто исправил и «Спасибо за исправление».
- **Напоминания** — за 24 часа до дедлайна бот упоминает тех, кто не сдал; после дедлайна присылает итог.
- **Статистика админу** — `/stats` (рейтинг, % выполнения, оценки, исправления), `/export` в CSV и ежедневный отчёт.

## Установка (можно с телефона)

### 1. Бот в Telegram
1. [@BotFather](https://t.me/BotFather) → `/newbot` → имя → юзернейм на `bot`. Сохраните **токен**.
2. `/mybots` → ваш бот → **Bot Settings → Group Privacy → Turn off** (иначе бот не видит сообщения).
3. В группе включите **Темы**, добавьте бота и сделайте **администратором** (удаление и закрепление сообщений).
4. Узнайте свой ID у [@userinfobot](https://t.me/userinfobot).

### 2. Cloudflare
1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатно).
2. **Workers & Pages → Create → Import a repository** → подключите GitHub → репозиторий `bshuhrat/bshuhrat`.
3. Имя проекта: **`telegram-tasks-bot`** (должно совпадать с `wrangler.toml`). Ветка — эта ветка с ботом. Остальное по умолчанию → **Deploy**.
   База данных D1 создастся сама.
4. Откройте Worker → **Settings → Variables and Secrets → Add**:

   | Имя | Тип | Значение |
   |---|---|---|
   | `BOT_TOKEN` | **Secret** | токен от BotFather |
   | `ADMIN_IDS` | Text | ваш ID (несколько — через запятую) |
   | `TIMEZONE` | Text | `Europe/Moscow` |
   | `DAILY_REPORT_TIME` | Text | `20:00` (необязательно) |

   Нажмите **Deploy / Save**.
5. Скопируйте адрес Worker (вида `https://telegram-tasks-bot.ИМЯ.workers.dev`) и откройте в браузере:
   ```
   https://telegram-tasks-bot.ИМЯ.workers.dev/setup?token=ВАШ_ТОКЕН
   ```
   Должно появиться «✅ Бот @… подключён».
6. Каждый админ пишет боту `/start` в личку.

> **Если ссылка `workers.dev` не открывается** (бывает у российских провайдеров) — откройте её через VPN
> или добавьте переменную `WORKER_URL` с адресом Worker (например `telegram-tasks-bot.ИМЯ.workers.dev`).
> Тогда бот подключится сам в течение минуты, браузер не нужен.

### Необязательные настройки

| Переменная | По умолчанию | Описание |
|---|---|---|
| `GROUP_ID` | — | работать только в этой группе |
| `REMIND_BEFORE_HOURS` | `24` | за сколько часов до дедлайна напомнить |
| `PHOTO_FIX_TIMEOUT_MIN` | `60` | через сколько минут вернуть кнопку исправления, если фото не прислали |
| `PHOTO_REMIND_HOURS` | `7` | через сколько часов напомнить о фото без исправления |
| `PHOTO_REMIND_FROM` / `PHOTO_REMIND_TO` | `09:00` / `23:59` | в какое время можно присылать эти напоминания |

## Как пользоваться

### Админ в теме группы
```
/topic Математика                         — название темы (новые темы определяются сами)
/welcome Здесь задачи по алгебре...       — описание темы (участники видят по /info)
/faq_add дедлайн | Сдать до пятницы 18:00 — автоответ на слово «дедлайн» в этой теме
/faq_del дедлайн                          — удалить автоответ
/task Решить задачи | Стр. 15, №1–10 | 30.10.2026 18:00
                                          — задание (описание и дедлайн необязательны)
/photo_topic                              — тема фото-исправлений (/photo_topic off — выключить)
/close 3                                  — закрыть задание №3, итог придёт в личку
/stat 3                                   — итог по заданию №3 в личку
```

### Участник
- **Сдать задание** — ответить (reply) на сообщение с заданием текстом, фото или файлом, либо написать `#сдаю`, если в теме одно задание. Отклонённую работу можно пересдать.
- `/tasks` — задания темы и мой статус, `/info` — описание, `/faq` — частые вопросы
- `/ask текст` — вопрос администратору, `/my` — моя статистика

### Тема фото-исправлений
1. Участник присылает фото (с комментарием или без) — бот отвечает на него яркой красной кнопкой **«📸 Отправить фото исправление»**.
2. Любой участник нажимает кнопку — кнопка исчезает, фото закрепляется за ним, и у него сразу открывается ответ
   с подсказкой «Прикрепите исправленное фото 📎» (остаётся нажать скрепку → камера или галерея;
   открыть камеру напрямую Telegram ботам не позволяет).
3. Он присылает исправленное фото.
4. Бот удаляет из чата фото-нарушение и фото-исправление (и свои служебные сообщения) и публикует оба фото
   одним альбомом с подписью: кто прислал нарушение, кто исправил (выделено жирным) и «🙏 Спасибо за исправление».
   Для этого у бота должно быть право администратора **удалять сообщения**.
   На самих фото бот рисует полосы: красную **«НАРУШЕНИЕ»** и зелёную **«ИСПРАВЛЕНО»** (через Cloudflare Images,
   бесплатно до 5000 фото в месяц). Если сервис недоступен, фото уходят без полос.

**Вернуть в работу**, если админ не согласен с исправлением: ответьте (reply) на альбом словом `вернуть`
(можно с причиной: `вернуть плохо видно`). Это может сделать только администратор (из `ADMIN_IDS` или админ группы);
на такое сообщение от обычного участника бот не реагирует. Бот сразу удаляет сообщение админа и альбом, а исходное
фото-нарушение публикует заново с пометкой «Возвращено в работу», причиной и красной кнопкой — всё внутри темы.

Тема для фото-исправлений задаётся ссылкой в `wrangler.toml` → `PHOTO_TOPIC` (сейчас
`https://t.me/c/3716710626/87`); фото в других темах бот не трогает. Если `PHOTO_TOPIC` пуст,
тема включается командой `/photo_topic`.

Если исправление не прислали за `PHOTO_FIX_TIMEOUT_MIN` минут, кнопка возвращается.
Если фото остаётся без исправления дольше `PHOTO_REMIND_HOURS` часов (по умолчанию 7), бот один раз напоминает
«⏰ Нужно исправить!» с кнопкой — только с `PHOTO_REMIND_FROM` до `PHOTO_REMIND_TO` (по умолчанию 09:00–23:59);
ночные напоминания переносятся на 9 утра.

### Тема поломок
Тема задаётся ссылкой `REPAIR_TOPIC` в `wrangler.toml` (сейчас `https://t.me/c/3716710626/91`).

1. Бот замечает сообщения о поломках по ключевым словам (готовый список для пиццерии: «не греет», «сломалась»,
   «течёт», «касса не», «холодильник не»… — смотреть `/kw`) и отвечает: «🛠 Нужна заявка — оформите заявку»
   с кнопкой **«📝 Сделать заявку»**. Когда появится ссылка на систему заявок, впишите её в `REPAIR_SYSTEM_URL` —
   кнопка будет сразу открывать систему; пока ссылки нет, кнопка показывает подсказку.
2. Бот спрашивает «⏰ Какой статус? Починили?» с кнопками **«✅ Починили»** и **«❌ Не поломка»**:
   через 4 ч, затем через 24 ч, затем через 72 ч и дальше каждые 7 дней, пока не ответят. График —
   переменная `REPAIR_SCHEDULE_HOURS` (по умолчанию `4,24,72,168`, последнее значение повторяется).
   Только с 9:00 до 23:59 (ночные напоминания переносятся на утро). Номеров у заявок нет.
3. Нажимать кнопки может любой участник, но с подтверждением тем же человеком (с текстом поломки),
   чтобы ничего не перепутать.
4. После «Починили» бот удаляет все напоминания по этой поломке, а первое сообщение меняет на «✅ Починили»
   (кто отметил, сколько была открыта). По желанию к нему можно прислать фото после ремонта ответом.
   «Не поломка» удаляет все сообщения бота по ней.
5. Ответы на сообщение о поломке новых заявок не создают. `/zayavki` — незакрытые поломки со ссылками.
   Админ меняет слова: `/kw_add слово`, `/kw_del слово`.

### Разбор отчётов ИИ (бесплатно)
Бот читает показатели на фото или скриншоте отчёта и пишет менеджеру, что не так, почему и что сделать.
Отчёт получают сразу несколько бесплатных моделей, а модель-судья (видит сам отчёт) выбирает лучший ответ:
- **Google Gemini** — если задан секрет `GEMINI_API_KEY` (бесплатный ключ из Google AI Studio); модель — `GEMINI_MODEL`
  (по умолчанию `gemini-flash-latest`). Если есть, он же и судья.
- **Kimi K2.6** и **Llama 4 Scout** в Cloudflare Workers AI (привязка `AI`, бесплатный дневной лимит; основная модель — `AI_MODEL`).

В заголовке видно, чей ответ выбран и почему; внизу — какие модели не ответили и с какой ошибкой.
- В любой теме: ответьте (reply) на фото отчёта словом `разбор` (или `/razbor`).
- В теме отчётов (ссылка в переменной `REPORT_TOPIC`, сейчас `https://t.me/c/3716710626/152`) бот разбирает каждое фото сам.
- Точка: по умолчанию ИИ разбирает **Москву 8** (`REPORT_LOCATION` в `wrangler.toml`); админ меняет командой
  `/tochka_set Москва 5`, `/tochka` — посмотреть. Другую точку можно указать в запросе: `разбор Москва 3`.
  Разбор: сравнение каждого показателя со строкой «Сеть», по каждой проблеме — причина (через связанные
  показатели) и поручения менеджеру пиццерии Додо (что и когда сделать). Коротко: «Главное», «Хорошо», до 3 пунктов
  «Что исправить» с действиями; общие слова («проанализировать», «оптимизировать») запрещены. Если ответила
  запасная модель, внизу видно, почему не ответила основная.
- Нормы, с которыми ИИ сравнивает показатели: `/normy` — посмотреть, `/normy_set доставка до 30 мин; списания до 2%` — задать (админ).
- Бот сразу пишет «⏳ Разбираю отчёт…», а через 1–2 минуты заменяет это сообщение разбором (ИИ работает в фоне,
  через планировщик). Если бесплатный лимит на сегодня исчерпан — бот так и напишет.
- Excel и PDF пока не поддерживаются — пришлите скриншот.

### Снять с контроля: удалить сообщение бота
Если администратор удалит сообщение бота (о поломке или напоминание о ней, кнопку под фото-нарушением,
сообщение с заданием), бот больше не пишет по этой поломке / фото / заданию. Telegram не сообщает ботам об
удалениях, поэтому бот проверяет это сам перед каждым напоминанием: если его сообщения нет — снимает с контроля
(для поломки заодно убирает остальные свои сообщения по ней). Обычные участники чужие сообщения удалять не могут,
так что это действие доступно только админам группы.

### Админ в личке бота
- карточки сдач с кнопками оценки (у нескольких админов карточка обновляется у всех)
- `/stats`, `/stat id`, `/pending`, `/requests`, `/export`, `/close id`

## Для разработчика

```bash
npm install
npm test            # сквозные тесты с имитацией Telegram и D1
npx wrangler deploy # деплой из консоли
```

```
src/index.js      вебхук, /setup, планировщик (cron каждую минуту)
src/group.js      команды и сообщения в группе
src/admin.js      личка админа: оценка, ответы, статистика
src/photofix.js   тема фото-исправлений
src/reports.js    разбор отчётов ИИ (Kimi в Workers AI)
src/repairs.js    тема поломок: просьба оформить заявку и уточнение статуса
src/services.js   публикация заданий, приём сдач, уведомления
src/stats.js      отчёты и CSV
src/scheduler.js  дедлайны, ежедневный отчёт
src/db.js         D1: таблицы создаются автоматически
src/banners.js    полосы для фото (генерирует scripts/make_banners.py)
```

Участник попадает в статистику («не сдали»), когда хотя бы раз пишет в группе или вступает в неё после
добавления бота — Telegram не даёт ботам получить полный список участников.
